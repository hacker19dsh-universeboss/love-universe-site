# A Little Universe of Us — V3 ♡

A static romantic interactive webpage, built with plain HTML, CSS and JavaScript. No build tools or backend required.

## Features
- Personalized welcome gate (visitor enters a name)
- Secret 3-digit keypad code (default `143`)
- Personalized letter, playlist links and animated flower gift
- Gift unlock progress bar and final message
- Mood picker with personalized responses
- Memory cards with tap-to-reveal messages
- Wish picker with animated confetti
- Local photo preview (images are not uploaded)
- Hidden easter egg: click the top-left brand 5 times, or double-click the heart line
- Responsive/mobile layout, reduced-motion support

## Customize
Open `index.html` in a text editor and edit `SECRET_CODE`, `LETTER`, `SONGS`, and `moodLines` / wish messages in the script.


## Deploy
Upload the project to a GitHub repository. For Netlify, import that repository and leave the build command blank and publish directory as the repository root. For Vercel, choose Framework Preset `Other`, no build command, and deploy the root directory.

## Privacy
Visitor name and selected photos are handled in the browser only. Photo previews use local browser object URLs and are not uploaded by this webpage.
